# Community Themes

Share your Modern reClock themes with the community.

## How to submit a theme

1. Export your theme as `.mrt` from the **Themes** tab in the widget settings
2. Open an issue on the [GitHub repo](https://github.com/YoannDev90/KDE-Modern-reClock/issues) with:
   - The `.mrt` file attached
   - A preview screenshot (optional, can be extracted from the .mrt)
3. The maintainer will review and add your theme

## How to install a theme

1. Go to **Themes** tab in widget settings
2. Click **Load Themes** to browse community themes
3. Click **Preview** → **Apply** on a theme you like

Or import a `.mrt` file directly via **Import .mrt...**.

## Theme structure

```
theme-name.mrt (zip archive)
├── theme.json          ← metadata + config
├── preview.png         ← HD preview screenshot
└── fonts/              ← optional embedded fonts
    └── FontName.ttf
```
